# Matrugaya Tirth frontend

This is a static Next.js website. All editable site content lives in `src/content`, and local images and videos live in `public`.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run lint
npm run build
```

The static site is generated in `out/`. Deploy that folder to any static hosting provider.

To change addresses, contact details, services, reviews, FAQs, or page copy, edit the appropriate file in `src/content` and run another production build.
